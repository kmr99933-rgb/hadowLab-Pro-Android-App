ShadowLab Pro — مشروع أندرويد

ما هذا؟
- مشروع Android WebView يضم واجهة ShadowLab Pro داخل تطبيق أندرويد.
- يعمل المحتوى الحالي محليًا، ولا يحتاج صلاحيات إنترنت.
- الدردشة الحالية واجهة تجريبية وليست متصلة بمحرك إجابات.
- هذه نسخة Debug للتجربة وليست إصدارًا موقّعًا للنشر على متجر Google Play.

أسهل طريقة لبناء APK من الهاتف باستخدام GitHub:
1. فك ضغط ShadowLabAndroid.zip.
2. أنشئ مستودعًا جديدًا على GitHub من المتصفح.
3. ارفع جميع محتويات المجلد إلى المستودع، بما فيها المجلد المخفي .github.
4. افتح تبويب Actions في المستودع.
5. اختر "Build ShadowLab Pro APK" ثم اضغط Run workflow.
6. بعد نجاح البناء، افتح تشغيل الـ workflow الناجح وانزل إلى Artifacts.
7. نزّل ShadowLab-Pro-debug-apk.zip وفك ضغطه لتحصل على app-debug.apk.
8. افتح APK على هاتفك واسمح بالتثبيت من هذا المصدر عند مطالبتك.

ملاحظات:
- لا ترفع مفاتيح API أو كلمات مرور إلى GitHub.
- إذا لم يظهر مجلد .github عند الرفع من الهاتف، استخدم خيار رفع الملفات من GitHub أو تطبيق Git مناسب وتأكد من رفعه.
- لتثبيت التطبيق، قد تحتاج تفعيل "السماح من هذا المصدر" للمتصفح أو مدير الملفات.
